# Accordion

## Core Specs

- wrapper: full width
- separators: 1px border-subtle
- trigger: 14px, 500–600, full width, 12–16px padding
- hover: surface-hover
- open: surface-secondary or unchanged surface with stronger heading
- panel: 12–16px horizontal, 12–20px vertical
- chevron: 16px, 150ms rotation

## Variants

- Default divided
- Flush inside a panel
- Bounded group with 1px border and md radius
- Multi-open for configuration sections

Do not use heavy independent cards for every accordion item.
