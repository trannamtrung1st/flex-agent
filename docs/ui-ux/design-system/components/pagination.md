# Pagination

## Core Specs

- font: 13px
- control height: 32–36px
- gap: 4px
- radius: sm
- border: 1px solid border-default on bounded controls
- active page: surface-selected + fg-brand
- hover: surface-hover
- focus-visible: 2px `border-focus` ring with 2px offset
- disabled: fg-disabled

For dense operational tables, prefer compact previous/next + page summary over long page-number lists when practical.
