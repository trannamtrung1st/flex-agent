# Tooltips & Popovers

## Tooltip

- max width: 260px
- padding: 6–8px horizontal, 5–7px vertical
- font: 12–13px
- radius: sm
- background: surface-inverse
- text: fg-inverse
- show delay: approximately 400ms for pointer hover; show immediately on keyboard focus when helpful

## Popover

- background: surface-elevated
- border: 1px border-default
- radius: md
- shadow: shadow-sm
- padding: 12–16px
- width: content-dependent

Use popovers for contextual detail, not critical workflows that require focus trapping or explicit completion; use dialogs for those.
