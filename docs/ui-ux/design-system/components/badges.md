# Badges and instrument marks

Do not use filled colored pills as status. Status is **text + node or glyph**.

## State node

5–7px bordered circle: dim at rest, amber solid when live/attention, teal
solid or check-ring when sealed/ready/complete.

## Seals and rings

Teal seal ring for released/sealed records. Drawn geometry, not a badge chip.

## Count / rank marks

Tabular mono in `fg-muted` or `fg-strong`. Not amber unless the value is the
attention object (for example remaining time).

## Rules

- Never encode Review versus Release as a single badge (`PC-01`).
- Never show unpublished Result state to Participants (`PC-03`).
