# Tabs

In-page tabs are a hairline-underlined row of uppercase mono tokens with a 2px
teal current underline. Never filled tab backgrounds.

- Use `role="tablist"` / `tab` / `tabpanel` or an equivalent disclosed pattern.
- Campaign lists are registries/tables, not a tab track of Campaign ids
  (`PC-06`).
- Do not use tabs to fake lifecycle unlock (`PC-07`).
