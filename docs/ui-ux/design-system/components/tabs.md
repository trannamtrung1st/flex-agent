# Tabs

## Default — Underline/Indicator

- height: 36–40px
- font: 13–14px, 500–600
- wrapper bottom border: 1px border-subtle
- active text: fg-strong or fg-brand
- active indicator: 2px brand-primary
- hover: fg-strong + subtle surface-hover when appropriate
- focus-visible: global focus ring or clearly visible inset focus treatment
- disabled: fg-disabled; no hover/activation

## Segmented Tabs

Use for tightly related alternate views such as Transcript / Evidence / Evaluation.

- bounded wrapper: 1px border-default, sm radius
- item height: 32–36px
- active: surface-selected + fg-brand

Do not use large pill tabs for primary application navigation.
